# Редактор экранов

Редактор открывается прямо здесь: [**/editor/**](/editor/){target="_self"}. Это статическая страница — она ничего не отправляет на сервер и не пишет на диск.

## Что умеет

- 3D-предпросмотр как в игре: пиксель текста 1/40 блока, строка 10 px, фон TextDisplay с теми же отступами, камера из глаз игрока. Шрифт и спрайты — настоящие, если рядом лежат ресурсы клиента (в опубликованной версии их нет — используется запасной шрифт и иконки предметов).
- Управление как в Blockbench: ЛКМ — вращение, СКМ/ПКМ — сдвиг, колесо — зум; виджеты тащатся мышью или гизмо, клавиши-стрелки двигают выбранный.
- Умные направляющие как в PowerPoint: края и центры соседей, равные зазоры и равные шаги центров, зеркало относительно центра экрана. Привязки считаются только по видимым в кадре виджетам.
- Инспектор всех полей: позиция, масштаб, tolerance, текст сегментами со спрайтами и цветами, кадровая анимация, hover-анимация, onClick, morph и якорь фона.
- Скрыть / заблокировать виджет, перетаскивание сегментов и кадров за ручку.

## Импорт и экспорт

- **Импорт .jmc** — вставьте текст экрана; скрипт `scripts/<id>.jmp` можно вставить во вкладке скрипта под предпросмотром.
- **Скачать** (Ctrl+S) — `screens/<id>.jmc` и, если у экрана есть обработчики, `scripts/<id>.jmp`. Положите их в `plugins/DisplayLib/`, hot reload подхватит.
- **Экспорт** — скопировать или скачать любую из вкладок.

Открытые экраны автосохраняются в браузере (localStorage) и переживают перезагрузку вкладки.

## Локальный запуск с ресурсами клиента

```bash
cd web-ui
npm install
npm run dev
```

Чтобы предпросмотр использовал шрифт и текстуры Minecraft, скопируйте из jar клиента `assets/minecraft/font/` и `assets/minecraft/textures/{font,item,block,gui,particle,...}` в `web-ui/public/assets/minecraft/` и выполните `npm run sprites` — подробности в `web-ui/README.md`. Файлы Mojang в репозиторий не входят.
