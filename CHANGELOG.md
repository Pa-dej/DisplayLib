# Changelog

Формат версий плагина: `<версия Minecraft>+<версия плагина>`; релиз делается тегом `v<версия плагина>`
(например `v3.1.0` → jar `DisplayLib-1.21.11+3.1.0.jar`, версия подставляется из тега).

## Unreleased

### Плагин
- `rotation` у виджета: поворот в плоскости экрана вокруг центра (градусы, `+` против часовой); hover-повороты складываются с ним.
- Тинт спрайтов: `color` у спрайт-сегмента, `spriteColor`/`hoveredSpriteColor` у `SPRITE_BUTTON`.
- Звуки: `clickSound` и `hoverSound` (ключ/константа/таблица `{ sound, volume, pitch }`/`false`).
- `hoverAnimation` `ROTATE`: скаляр `angle`, ось `axis` (`[0,0,1]` - в плоскости экрана).
- Скрипт: `widget.rotation/scale/translation(..., ticks)` с интерполяцией клиента, `widget.sprite(atlas, name, color)`, `widget.spriteColor(color)`.
- `/displaylib validate` - отчёт о проблемах экранов (дубли id, клики в никуда, скрипты и функции, статичные виджеты).
- Morph-переходы между экранами (`dyn morph = { enabled, duration, steps }`), якорь фона (`anchor`), кадровая анимация текста (`frames`), статический разбор экранов (не тикаемые виджеты), `onClick: true`.

### Редактор
- Превью hover-анимаций, мультивыделение (Shift+клик, рамка, Ctrl+A) с выравниванием и распределением, копирование/вставка виджетов через буфер как `.jmc`-фрагмент.
- Проверка экрана по правилам плагина (бейджи и список), превью morph между открытыми экранами, браузер ассетов по категориям, тинт спрайтов, поворот, звуки.
- Надёжный Ctrl+Z/Y (любая раскладка, без пустых шагов), экспорт zip всех экранов, импорт именует файл по id экрана.
- Шрифт и спрайты клиента 1.21.11 входят в редактор; палитра «лазурь».

### Репозиторий
- Монорепо: `plugin/`, `web-ui/`, `docs/` (VitePress), GitHub Actions: сборка и релиз плагина по тегу, GitHub Pages с документацией и редактором.

## 3.0.0

- Переход с YAML на Jumper: экраны `.jmc`, скрипты `.jmp`, политика `scripts.jma`, hot reload, таймеры, storage.
- `SPRITE_BUTTON` и спрайты атласа в тексте (клиент 1.21.9+), точная зона наведения по центру текста.
