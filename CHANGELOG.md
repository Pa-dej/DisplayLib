# Changelog

Формат версий плагина: `<версия Minecraft>+<версия плагина>`; релиз делается тегом `v<версия плагина>`
(например `v3.1.0` → jar `DisplayLib-1.21.11+3.1.0.jar`, версия подставляется из тега).

## Unreleased

### Плагин
- Частицы без коллизий считаются в отдельном потоке «DisplayLib Particles» (`particles.async: true`, только вместе с пакетами): основной поток лишь создаёт частицы и выбирает зрителей, пакеты потока отправляет в начале следующего тика - кадры приходят клиенту ровно раз в тик. На замере 1000 частиц: работа частиц в основном потоке 1,57 → 0,53 мс за тик. Эффекты с коллизиями - как раньше в основном потоке.
- Частицы показываются пакетами, без сущностей на сервере (`particles.packets: true` в `config.jmc`, по умолчанию): нет хранения в чанках, трекера, телепортов и удаления сущностей - на замере это ~70% стоимости частиц. Зрители - владелец или игроки не дальше `particles.viewDistance` (96) от точки запуска. На другой версии сервера - автоматически сущности, как раньше. Сборка: paperweight-userdev (dev bundle Paper 1.21.11), Gradle 9.7 (плагины сборки требуют 9.7+). Пакеты тика уходят одной связкой на игрока; пока рядом нет зрителей, новые частицы не появляются. Подбор кадров вида для линейного размера без смены цвета - за O(n) вместо O(n²).
- Частицы, заданные явно: `Particles.playPieces(effect, center, owner, List<ParticlePiece>)` - текст, смещение, размер, поворот каждой частицы; `TextShatter` / `Particles.shatter("слово")` - слово висит и через `hold` тиков рассыпается на буквы по эффекту; команда `/displaylib particle shatter <текст>`, пример `letters`.
- Цвет частицы (`colors` / `animation.color`) красит и спрайты и головы без своего цвета - как в предпросмотре редактора; раньше они оставались белыми. Сегмент со своим `color` сохраняет его.
- Частицы `TEXT`: любой вариант текста может быть анимацией кадров `{ frames: [...], frameInterval }` (как у кнопок экранов) - по кругу или один проход за жизнь (`framesOverLife`), `frameStart: "random"`; пример `smoke` из кадров ванильного дыма.
- Частицы: кадры размера/поворота/цвета подбираются по кривой - линейный размер идёт одним пакетом на всю жизнь, `easing`, градиенты и кривые прозрачности дробятся ровно настолько, насколько нужно глазу (было: каждые `keyframeTicks`). Изгиб отрезков кривой `opacity` (Безье: `[доля, значение, [x, dy]]`). `glowColor` - цвет контура свечения у `ITEM`/`BLOCK`.
- Частицы: тип `PIXEL` (цветной квадрат с прозрачностью), цвет и непрозрачность во времени (`animation.color` в OkLab, `animation.opacity`; клиент интерполирует их вместе с трансформацией), силы `attract` / `attractAxis` и `wander`, `emitter.duration: -1`; примеры `flame`, `water_splash`, `fireflies` по мотивам text-display-experiments (Heledron).
- Частицы из Display-сущностей: эффекты `particles/*.jmc` (текст/спрайты, предметы, блоки; формы испускания, разлёт, гравитация, сопротивление, опциональные коллизии с отскоком, размер и вращение во времени, `viewers: "owner"`), запуск `/displaylib particle` и Java API `Particles`. Движение ведёт клиент по ключевым кадрам (`keyframeTicks`) - сервер не телепортирует частицы каждый тик. Лимит `particles.maxAlive`. Примеры: `sparkle`, `confetti`, `poison`, `coin_fountain`, `embers`.
- `onClose(reason)` вызывается при любом закрытии экрана - переключение, выход, смерть, смена мира, телепорт, инвентарь, дистанция, выключение сервера; причина приходит аргументом (`"close"`, `"switch"`, `"quit"`, ...), Java-енум `CloseReason`. Закрытие/переключение из `onClose` игнорируются.
- `storage` сохраняется на диск (`data/storage/*.jmc`): данные игрока переживают выход и перезапуск, у публичного экрана - общее хранилище на экран; `dyn storage = { persist, autosaveSeconds }` в `config.jmc`.
- Публичные экраны, поставленные `/displaylib openpublic`, переживают перезапуск: `data/public_screens.jmc`, восстановление при запуске и при (повторной) загрузке мира; из Java - `openPublicScreen(..., persistent = true)`. `listpublic` показывает и экраны, ждущие своего мира.
- `DisplayClickEvent` и для публичных экранов, с `getScreenId()`, `getWidgetId()`, `isPublicScreen()`.
- Зона наведения поворачивается вместе с виджетом (`rotation`).
- `rotation` у виджета: поворот в плоскости экрана вокруг центра (градусы, `+` против часовой); hover-повороты складываются с ним.
- Тинт спрайтов: `color` у спрайт-сегмента, `spriteColor`/`hoveredSpriteColor` у `SPRITE_BUTTON`.
- Звуки: `clickSound` и `hoverSound` (ключ/константа/таблица `{ sound, volume, pitch }`/`false`).
- `hoverAnimation` `ROTATE`: скаляр `angle`, ось `axis` (`[0,0,1]` - в плоскости экрана).
- Скрипт: `widget.rotation/scale/translation(..., ticks)` с интерполяцией клиента, `widget.sprite(atlas, name, color)`, `widget.spriteColor(color)`.
- `/displaylib validate` - отчёт о проблемах экранов (дубли id, клики в никуда, скрипты и функции, статичные виджеты).
- Morph-переходы между экранами (`dyn morph = { enabled, duration, steps }`), якорь фона (`anchor`), кадровая анимация текста (`frames`), статический разбор экранов (не тикаемые виджеты), `onClick: true`.

### Редактор
- Кадры текста у кнопок экранов редактируются так же, как у частиц: кнопка «Кадры» у `text`/`hoveredText`, лента миниатюр с проигрыванием, правка выбранного кадра (общий `FramesEditor`).
- Частицы: варианты текста карточками, у каждого - кнопка «Кадры» (лента миниатюр с проигрыванием, порядок перетаскиванием); предпросмотр и оценка нагрузки учитывают смену кадров. Файл с новыми возможностями помечается в заголовке: «нужна сборка от 18.10.2026».
- Плавность: подложка выбранного сегмента и полоска вкладки переезжают, окна и всплывающие панели появляются с анимацией, поля и секции инспектора - мягко, смена темы - без вспышки; учитывается «уменьшить движение» системы. Оценка нагрузки частиц считается в Web Worker и не подтормаживает интерфейс. Шапка не ломается на узких экранах.
- Шкала нагрузки экрана и эффекта частиц: кольцо от зелёного к красному по примерной оценке времени сервера, трафика на игрока и числа сущностей, с разбором слагаемых, советами и допущениями (игроки, запуски).
- Частицы: свой выбор цвета (HEX/RGB/HSL, пипетка, вставка любого формата), один список вариантов текста, выбор «постоянный цвет / градиент по жизни», градиент и кривая прозрачности правятся мышью (кривая - с узлами Безье), «линейная / своя» кривая размера с оценкой пакетов, контур свечения в предпросмотре, быстрый экспорт (Ctrl+E).
- Превью hover-анимаций, мультивыделение (Shift+клик, рамка, Ctrl+A) с выравниванием и распределением, копирование/вставка виджетов через буфер как `.jmc`-фрагмент.
- Проверка экрана по правилам плагина (бейджи и список), превью morph между открытыми экранами, браузер ассетов по категориям, тинт спрайтов, поворот, звуки.
- Надёжный Ctrl+Z/Y (любая раскладка, без пустых шагов), экспорт zip всех экранов, импорт именует файл по id экрана.
- Шрифт и спрайты клиента 1.21.11 входят в редактор; палитра «лазурь».
